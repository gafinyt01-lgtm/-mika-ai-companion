# Mika AI Companion — UI 0.1

Starter UI untuk virtual companion Mika.

## Isi versi 0.1
- Tampilan full-screen virtual companion.
- Karakter Mika dengan enam ilustrasi ekspresi.
- Animasi idle sederhana (floating, glow, sparkle).
- Tombol pemilih ekspresi untuk demo.
- Panel chat dengan balasan simulasi berdasarkan kata kunci.
- Layout responsif untuk HP dan desktop.

## Menjalankan
```bash
npm install
npm run dev
```
Buka http://localhost:3000.

## Penting
Versi ini masih UI prototype. Chat belum memakai model AI/API, suara belum aktif, dan ilustrasi belum berupa model Live2D rigged. Tombol suara saat ini hanya mengubah status UI. Jangan masukkan API key rahasia ke kode frontend.

## Deploy
Upload isi folder project ke repository GitHub, lalu import repository tersebut di Vercel.
